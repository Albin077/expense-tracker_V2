# EXP Tracker

A full-stack expense tracking application with:

- **Backend (FastAPI + Supabase)**  
  Handles authentication, expense/income routes, and analytics.

- **Frontend (HTML, CSS, JS)**  
  Provides login, home, tables, workspace search, and analytics charts.

## 🚀 Setup

### Backend
```bash
cd EXP_backend
pip install -r requirements.txt
uvicorn app.main:app --reload
